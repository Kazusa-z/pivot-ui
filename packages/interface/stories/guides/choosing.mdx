## 相近组件怎么区分

**同一个值的几种形态**（见[命名约定](?path=/docs/guides-介绍--docs)）：`*Input` 直接输入 → `*Field` 紧凑组合 → `*Picker` 点开浮层 → `*Editor` 完整展开。属性面板一行放 `Field` 或 `Picker`，侧栏或独立面板放 `Editor`。

| 容易混淆                                        | 区别                                                                                                                    |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `Slider` / `SliderField` / `PartitionSlider`    | `Slider` 只有滑块；`SliderField` 是输入框 + 滑块；`PartitionSlider` 拖动分界点把总量分成多段                            |
| `PartitionSlider` / `NumericDistributionEditor` | 前者是"分段比例"，后者是"随机分布"（固定值、范围或曲线）                                                                |
| `ColorField` / `ColorPicker` / `ColorEditor`    | 字段带 HEX 和透明度输入；Picker 只有色块按钮；Editor 是展开的完整取色面板                                               |
| `ColorRampEditor` / `ColorAlphaRampEditor`      | 前者每个色标自带透明度；后者颜色轨和透明度轨分开编辑                                                                    |
| `Section` / `Accordion`                         | `Section` 是独立的可折叠分组；`Accordion` 是一组互相关联、通常一次只展开一个的分组                                      |
| `Separator` / `SectionDivider`                  | 前者是一条线；后者是带文字的分组标题线                                                                                  |
| `Table` / `DataTable` / `CollectionEditor`      | `Table` 是可自由组合的表格部件；`DataTable` 按列配置生成表格并支持选中；`CollectionEditor` 管理可增删、改名、排序的条目 |
| `Popover` / `Tooltip` / `HoverCard`             | Popover 点击打开、可交互；Tooltip 悬停显示一句说明；HoverCard 悬停显示较丰富的预览                                      |
| `Dialog` / `AlertDialog`                        | Dialog 承载表单或详细内容；AlertDialog 只用于必须明确回答的决定                                                         |
