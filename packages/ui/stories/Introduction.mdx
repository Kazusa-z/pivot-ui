# Pivot UI Editor

`@pivot-ui/editor` is a React component library for building browser-based 3D editors, inspectors and content tools. It is engine agnostic and can bind to any scene graph, store or plain JavaScript object.

The library includes foundational controls such as `Button`, `Input` and `Flex`, plus editor-specific components including `ColorPicker`, `GradientSlider`, `ParticleSlider`, `BezierCurveEditor`, `AssetItem`, `Tree` and `Table`.

## Features

- **Editor-focused components** — inspector controls, overlays, color tools, asset views and hierarchical data.
- **Controllable state** — most interactive components support controlled and uncontrolled usage.
- **Theme support** — consistent light and dark themes driven by shared design tokens.
- **Accessible primitives** — interactive behavior is built on Radix UI.
- **Ref forwarding** — components expose their underlying DOM element where useful.
- **TypeScript** — public props and component APIs are fully typed.

## Usage

```tsx
import { Button } from '@pivot-ui/editor'

export function App() {
  return <Button>Save</Button>
}
```

## Styling

Components are styled with Panda CSS. The consuming application must run Panda's PostCSS plugin and import the package layer entry once:

```ts
import '@pivot-ui/editor/panda.css'
```

The package CSS entry declares layer order; Panda generates the component styles during the application build. See the repository integration guide for the complete Panda configuration.

## Theming

Open **Foundations / Design System / Overview** to compare light and dark components and explore the design tokens. The **Theme** toolbar switches every story's components and overlays between light and dark mode.

Wrap the application in `ThemeProvider` and use `useTheme` to switch modes:

```tsx
import { ThemeProvider, useTheme } from '@pivot-ui/editor'

function ThemeToggle() {
  const { theme, setTheme } = useTheme()
  return <button onClick={() => setTheme(theme === 'dark' ? 'light' : 'dark')}>Toggle theme</button>
}

export function App() {
  return (
    <ThemeProvider>
      <ThemeToggle />
    </ThemeProvider>
  )
}
```
