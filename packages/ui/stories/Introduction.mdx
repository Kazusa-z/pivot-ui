# Introduction

`@pivot-ui/editor` is a React component library for building 3D editor interfaces in the browser. It is engine-agnostic and can drive any scene graph or plain data.

In addition to including some basic components such as `<Button>` or `<Input />`, it also provides some dedicated components like `<ColorPicker />`, `<GradientSlider />`, `<ParticleSlider />`, `AssetPicker` and some hooks to help you build your own graphic editor.

You can also use it to build custom editor panels and plugins.

Accessibility is a key part of the package, all components are designed to be accessible. Besides, we also forward the ref to the underlying DOM element to let you control the component directly.

## Local usage

This package is developed and consumed inside the local Pivot UI pnpm workspace. It is not published to npm; use `workspace:*` or link the package from another local project.

## Usage

Import the components from the package in your application.

```tsx
import { Button } from '@pivot-ui/editor'

function App() {
  return <Button>Pivot UI</Button>
}
```

Note: You have to keep your application with some **reset css** to make sure the components work correctly. If not you could use `resetStyle()` which exported from `@pivot-ui/editor` to reset the style.

> This package does not use the `z-index` style.
