# Pivot UI Form Items

`@pivot-ui/gui` provides individual React form items for inspectors and property editors. Compose the fields in your application's layout and keep their values in application state.

## Start with local state

```tsx
import { useId, useState } from 'react'
import { FormItemGroup } from '@pivot-ui/gui'

import { Input, Vector3Input, NumericSlider, PropertyRow, PropertyLabel, PropertyControl } from '@pivot-ui/react'

export function Inspector() {
  const nameId = useId()
  const positionId = useId()
  const opacityId = useId()
  const [name, setName] = useState('Object')
  const [position, setPosition] = useState({ x: 0, y: 0, z: 0 })
  const [opacity, setOpacity] = useState(1)

  return (
    <div style={{ width: 360 }}>
      <FormItemGroup label="Object">
        <PropertyRow>
          <PropertyLabel htmlFor={nameId}>Name</PropertyLabel>
          <PropertyControl association="control">
            <Input id={nameId} value={name} onValueChange={setName} />
          </PropertyControl>
        </PropertyRow>
        <PropertyRow>
          <PropertyLabel id={positionId}>Position</PropertyLabel>
          <PropertyControl association="group" labelledBy={positionId}>
            <Vector3Input value={position} onValueChange={setPosition} />
          </PropertyControl>
        </PropertyRow>
        <PropertyRow>
          <PropertyLabel htmlFor={opacityId}>Opacity</PropertyLabel>
          <PropertyControl association="control">
            <NumericSlider
              id={opacityId}
              label="Opacity"
              value={opacity}
              onValueChange={setOpacity}
              min={0}
              max={1}
              step={0.01}
            />
          </PropertyControl>
        </PropertyRow>
      </FormItemGroup>
    </div>
  )
}
```

A fixed `value` without an updating callback cannot accept edits. The stories use local state, display the current value and offer Reset so you can see the whole interaction without a backend.

Later, the application can route edits through a C++/Qt adapter and pass the resulting snapshots back as props. Data loading, commands and synchronization stay in the application.

## Explore the fields

- Text, choices and actions moved to the unified explorer on port 6009; the seven corresponding FormItem wrappers have been removed.
- Numbers and geometry moved to port 6009: InputNumber, Slider, DistributionSlider, NumericSlider, Vector2/3/4Input and RectInput.
- Display: read-only values and images.
- Specialized values: Color, Gradient, ParticleCurve and AssetPicker.
- Composition: FormItem, Group and Array.

Gradient and particle fields use `onValueChange(value, type)`. Asset selection uses `onSelect` and `onDelete`. Arrays use `items`, `onAdd`, `onDelete` and `onRename`. Their stories demonstrate how to store each result.

## Styling and themes

Configure Panda CSS to scan the form, editor and unified interface source, then import `@pivot-ui/gui/panda.css` in your application. The CSS entry declares layer order; Panda generates the styles during the build.

Use `ThemeProvider` from `@pivot-ui/editor` in your application. This Storybook's toolbar applies the same light and dark themes to every example.
